nginx 뒤에서 SSE를 쓸 때

Oct 04, 20262 min read

  • nginx
  • sse
  • 요령

nginx를 앞에 두고 SSE를 쓸 때 챙길 설정들.

  • 버퍼링을 끈다. proxy_buffering off; 켜 두면 nginx가 응답을 모았다가 보내서 이벤트가 제때 도착하지 않는다.
  • 읽기 제한 시간을 늘리거나, 서버가 주기적으로 무언가를 보낸다. proxy_read_timeout의 기본값은 60초다. 그동안 뒤쪽 서버가 아무것도 보내지 않으면 nginx가 연결을 끊는다. 서버가 주기적으로 ping이나 주석 줄을 보내는 이유 중 하나다.
  • HTTP/1.1로 뒤쪽에 연결한다. proxy_http_version 1.1;과 proxy_set_header Connection "";
  • Host 헤더를 넘긴다. proxy_set_header Host $host; 넘기지 않으면 nginx는 뒤쪽 서버 묶음(upstream)의 이름을 Host로 보낸다. 그 이름에 밑줄이 있으면 톰캣이 잘못된 호스트 이름으로 보고 400을 돌려준다.

뒤쪽 서버 하나가 죽으면 nginx는 접속 거절을 보고 같은 요청을 다른 서버로 넘기고, 죽은 서버를 잠시(기본 10초) 제외한다.
